# Annie's K-Pop Blog

## What is the Project About?

Annie's K-Pop Blog is a multi-page website created for K-Pop fans to explore K-Pop-related content. The website includes recent comeback and release information, song and album reviews, and an About Me page.

The project was created to provide a place for K-Pop fans to explore content and share their interests and opinions.

## Pages

- **Home** - Introduction to the website and its content
- **About Me** - A biography and information about the creator
- **Comebacks** - Recent K-Pop comebacks and releases
- **Reviews** - Song and album reviews
